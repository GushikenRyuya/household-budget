# ふたりの家計簿

ふたりのスマホから入力できる家計簿です。月別・年別の支出を集計します。
タスク管理アプリと同じ作り(GitHub Pages + Firebase Firestore)なので、新しい契約や設定はほぼ不要です。

## できること

- 入力: 金額・日付(初期値は今日)・区分(共有/個人)とカテゴリー(共有15種・個人20種)・支払い者(ひなた/ぐしけん)と支払方法(現金/カード/コード決済/口座引落)
  - 支払い者と支払方法の両方が未選択のときは、「共有現金」として記録されます
- 収入: 「支出/収入」を切り替えて、給与・単発バイトを入力(受取人はひなた/ぐしけん)
- テンプレート: 毎月入れるものを「マスタ」タブで登録しておくと、入力タブのボタンを押すだけで入力欄にセットされます(内容を確認して「追加する」を押す)
- 入力履歴: 入力タブに半年分を、月ごとにたたんで表示。月の見出しを押すと開き、記録をタップして修正・削除できます
- 月別・年別: 一番上に収支(収入 − 支出、プラスもマイナスも)、収入の内訳、支出の合計(共有・個人)、共有カテゴリ別・個人カテゴリ別、支払い者別、支払方法別。「すべて/共有/個人」で表示を切り替え。年別は月ごとの収支も表示
- 変更はふたりの画面にリアルタイムで反映されます

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 |
| `firebase-config.js` | Firebase の接続設定(タスク管理と同じ値を設定済み) |
| `firestore.rules` | Firestore のルール(**タスク管理用のルールも含んだ統合版**) |

## 公開手順

### 1. Firestore のルールを更新する(必須)
1. Firebase コンソール →「Firestore Database」→「ルール」タブ
2. 中身を全部消して、`firestore.rules` の内容を貼り付け →「公開」

※ 今までのタスク管理用ルールも入っているので、タスク管理アプリもそのまま使えます。
※ テンプレート(マスタ)を使うには、このルールの貼り直しが必要です(テンプレート用の項目が増えています)。

### 2. GitHub にアップロードする
タスク管理と同じリポジトリに、フォルダごと追加するのが簡単です。
1. リポジトリのトップで「Add file」→「Upload files」
2. `household-budget` フォルダ(中の3ファイル)をドラッグして、「Commit changes」
3. 1〜2分後、次のURLで開けます
   `https://<ユーザー名>.github.io/<リポジトリ名>/household-budget/`

スマホのブラウザで開き、「ホーム画面に追加」をするとアプリのように使えます。

## 注意

- 無料の GitHub では、サイトは公開されます。URLを知っている人は誰でも開けるので、URLは他人に教えないでください。
- 金額は整数(円)だけ保存できます。
- カテゴリー・支払方法を変えたいときは、`index.html` 冒頭の `CATEGORIES` と `METHODS` を編集します。名前を変えると、過去の記録は元の名前のまま残ります。
- Firestore の無料枠(保存1 GiB、読み取り5万回/日、書き込み2万回/日)に、ふたりの利用なら十分収まります。
